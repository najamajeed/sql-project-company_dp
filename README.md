# sql-project-company_dp
This project contains SQL queries written using MySQL to practice and understand fundamental SQL concepts. It uses a college database (college_db) containing student and enrollment information.
MySQL Student Database – SQL Practice

This project includes SQL queries created using MySQL to practice basic SQL concepts with a college database (college_db) containing student and enrollment details.

Topics Covered

* SELECT statements
* WHERE clause
* AND, OR operators
* NOT IN operator
* BETWEEN operator
* LIKE operator and pattern matching
* NULL and IS NULL conditions
* ORDER BY (Ascending and Descending)
* LIMIT clause
* Filtering and sorting student data
* Identifying top-performing and youngest students

Objective

To gain practical experience in SQL by writing queries and exploring student and enrollment data.

Tools Used

* MySQL
* MySQL Workbench
